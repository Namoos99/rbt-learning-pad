# RBT Learning Pad

An interactive study companion for Registered Behavior Technician (RBT) trainees. It helps new RBTs learn the 2026 exam content efficiently, think through ethics before it matters, and keep a private reflection journal, so more time goes to direct client work.

Built by Namoos Haider, a former senior RBT and founding RBT at a severe-behavior ABA clinic, now an MS student in Applied Data Science & AI at the University of Denver.

## What's inside

- **Dashboard:** exam blueprint, progress by domain, a "next step" suggestion, and the certification roadmap
- **Study:** all 43 tasks from the RBT Test Content Outline (3rd ed.) in plain language
- **Practice:** scenario questions with explanations, flashcards, and a session-note coach
- **Ethics Lab:** dilemmas, a four-question pocket check, and the RBT Ethics Code (2.0) at a glance
- **Knowing the Kiddos:** assent, communication, sensory needs, dignity, and culture
- **Signs:** 20 everyday ASL signs with illustrations, memory hooks, and a practice drill
- **Reflection Journal:** guided prompts and a running list of questions for supervision
- **Resources:** official BACB documents, free exam guides, and free ASL courses

## Run it

Open `index.html` in any browser. No install or build step. Progress and journal entries save in your browser.

To publish it, enable GitHub Pages for this repo (Settings → Pages → deploy from `main`, root folder).

## Notes

- Content is paraphrased from BACB documents. This is an independent study tool, not a 40-hour training, and it isn't affiliated with the BACB. Always confirm current requirements at [bacb.com](https://www.bacb.com/rbt/).
- Sign illustrations are AI-generated and reviewed for handshape and movement. Check signs against a native signer on video before teaching them.
- The AI "explain it another way" and note-rewrite features only work when the pad runs as a Claude artifact; everything else works anywhere.
